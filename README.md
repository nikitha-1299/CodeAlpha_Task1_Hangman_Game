# CodeAlpha_Task1_Hangman_Game
Python-based Hangman word guessing game developed for CodeAlpha internship.
🎮 CodeAlpha Task 1: Hangman Game

📌 Project Overview

This project is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

The game randomly selects a word from a predefined list, and the player tries to guess the word one letter at a time.

🎯 Features

- Random word selection
- Five predefined words
- Letter-by-letter guessing
- Tracks incorrect guesses
- Maximum of 6 incorrect attempts
- Displays win or game-over messages
- Prevents repeated letter guesses

🛠️ Technologies Used

- Python
- "random" module
- "while" loop
- "if-else" statements
- Strings and lists
- User input and output

▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:

python hangman.py

🎮 How to Play

1. Run the program.
2. Enter one letter at a time.
3. Correct guesses reveal letters in the word.
4. Incorrect guesses increase the error count.
5. Guess the complete word before reaching 6 incorrect guesses to win.
